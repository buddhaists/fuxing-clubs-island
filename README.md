## ✨ 核心特色與架構
1. **3D 天空之城八角浮空群島**：
   * 包含中心「福星總部核心島」與 5 座主題浮空群島（活力動感體育島、天籟創藝美育島、智創探索科技島、博學文采語文島、全人共融博雅島）。
   * 手作切角岩層底座、雲海浮空特效、日落傍晚與星夜即時天色變換。
2. **20 社團動態微縮模型與師生教學現場**：
   * 棒球、籃球、桌遊、西洋棋、陶藝、程式、漫畫、舞蹈、蝶古巴特、手作、街舞、柔道、陶笛、剪紙、繪本、直排輪、足球、樂樂棒球、田徑。
   * 依據時段動態呈現：白天上課全員到齊展示教學動態；傍晚與夜間非上課時段沉靜休養，點擊社團即時召喚師生並歡呼跳動 3 次後恢復原動作。
3. **系統管理員統一後台**：
   * 提供 20 社團全欄位編輯、JSON / CSV 檔案批次匯入上傳、消息公告發布與安全密碼管理。
4. **選課輔助工具**：
   * 1～6 年級選課導航矩陣、適性小測驗、線上志願回條列印、自由漫遊 RPG 模式。
